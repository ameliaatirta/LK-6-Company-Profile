## Deskripsi Website
Website Company Profile untuk TIRTA Group (Est. 2011), sebuah holding company yang menaungi 4 lini usaha di bidang fashion, barang kreatif/kriya, dan manufaktur bordir (ESEA, KALA, ANANTA, TIRTABORDIR). Website ini dirancang dengan gaya *editorial minimalis* menggunakan React dan Tailwind CSS.

## Fitur Utama
- Navigasi responsif dengan React Router
- Lookbook Carousel interaktif pada Beranda
- Filter kategori pada halaman Portofolio
- Form kontak minimalis dengan validasi sederhana
